HOW TO READ THE BOARD

A rank has a scope.

Compare matching workloads

Rankings apply within the same model and checkpoint, task suite, context and load profile, and latency limits. Each record will identify the recipe’s artifacts and quantization procedure, engine/version, build and launch settings, KV precision, memory use, and actual batching where available.

Qualify before ranking

Only recipes that pass the declared quality and serving-correctness gates qualify for ranking. Failures and inconclusive decisions will remain visible with their evidence. A matched-quantized reference establishes a different claim from preservation against original precision.

Count useful work

Goodput is correct, valid responses meeting the declared service-level objective per second. We will also report raw tok/s and measured ms/token, with aggregate throughput distinguished from per-stream latency.

Inspect the evidence

Each entry will link to a frozen manifest, commands, paired outcomes, confidence bounds, timing records, errors, and evaluation duration. Any external figures used for context will be labeled reported and excluded from our rankings.
